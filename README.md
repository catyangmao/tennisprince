# 网球王子 🎾

帮中国网球新球迷,看懂比赛、参与比赛。

- 单页工具(移动优先),马尔可夫解析引擎算整场胜率
- 数据管道:GitHub Actions 每天两次(北京 10:17 / 18:17)自动抓取网球赛程与比分 → `data.json` → 页面打开自动拉取
- 纯积分竞猜游戏,不涉任何赌博;积分存用户自己手机本地

## 结构

- `index.html` — 全部功能(单文件)
- `fetch-data.js` — 数据抓取与格式转换
- `data.json` — 抓取产物(自动更新)
- `.github/workflows/daily-data.yml` — 定时任务

## 本地运行

直接浏览器打开 `index.html`,或任意静态服务器。数据拉取失败时自动回退到内置快照。
